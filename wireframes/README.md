# Wireframes

Put wireframe pictures here (`.excalidraw.svg`, `.svg`, `.png` or `.jpg`).

**Start the file name with the issue number it belongs to**, then a dash and a short name:

- `7-request-form.excalidraw.svg` → shows under issue **#7**, and in its feature's **Wireframes** tab
- `5-overview.png` → shows in feature **#5**'s Wireframes tab

The handbook picks them up by itself on the next publish.
