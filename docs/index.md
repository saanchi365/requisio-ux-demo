# Requisio handbook

Welcome! This handbook explains **what Requisio does**, **how each feature works**, and **who uses it**.

*Requisio is a made-up purchase-request app, used to practise UX documentation.*

## How to read this handbook

- **Features** explain one part of the product each. Use the tabs on each feature page.
- **Who uses Requisio** describes the people using it and their experience.
- Something unclear? Use the **💬 comment link** at the bottom of each feature page.
