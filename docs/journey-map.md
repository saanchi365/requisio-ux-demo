# Journey map – raising a purchase request

*Made-up content for the Requisio demo.*

| | 1. Start | 2. Fill details | 3. Attach quote | 4. Submit | 5. Wait & track | 6. Decision |
|---|---|---|---|---|---|---|
| **Doing** | Clicks "New request" | Picks a category, fills item, cost, reason | Uploads the vendor's quote | Sends for approval | Checks the status | Gets approved or asked for changes |
| **Feeling** | Hopeful | Unsure which category | Annoyed if it's not accepted | Relieved | Anxious | Happy, or frustrated |
| **Needs** | Find the button fast | Clear categories, few fields | Any common file type | See who will approve | A clear status and next step | A clear reason if rejected |
| **Opportunities** | "New request" always visible | Catalog items fill fields | Read the amount from the quote | Show the approval route before submitting | Notifications | Edit and resubmit in one click |
