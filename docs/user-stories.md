# User stories

*Made-up content for the Requisio demo.* Each story says who wants something, what they want, and why.
Anyone can comment on a story on the website; the owner decides what is added.

## Requester
- As a **requester**, I want to **pick a ready-made catalog item**, so that **I don't have to type the details again**.
- As a **requester**, I want to **see who will approve my request before I submit it**, so that **I know how long it may take**.
- As a **requester**, I want to **know why a request was rejected**, so that **I can fix it and send it again**.

## Approver
- As an **approver**, I want to **see everything waiting for me in one list**, so that **nothing gets forgotten**.
- As an **approver**, I want to **hand my approvals to a colleague while I'm away**, so that **requests aren't stuck**.

## Admin
- As an **admin**, I want to **set approval rules by amount**, so that **expensive requests always reach Finance**.
- As an **admin**, I want to **be warned when two rules clash**, so that **requests don't follow the wrong route**.
