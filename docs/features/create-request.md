# Create a purchase request

Employees raise a request in a few steps, from a **catalog item** or a **custom item**.

**Status:** In progress · **Priority:** P0 · **Board:** [Requisio – UX demo](https://github.com/users/saanchi365/projects/9)

=== "What was asked for"

    | Issue | Requirement |
    |---|---|
    | [#6](https://github.com/saanchi365/requisio-ux-demo/issues/6) | Start a new request |
    | [#7](https://github.com/saanchi365/requisio-ux-demo/issues/7) | Fill in request details |
    | [#8](https://github.com/saanchi365/requisio-ux-demo/issues/8) | Attach a vendor quote |
    | [#9](https://github.com/saanchi365/requisio-ux-demo/issues/9) | Submit for approval |

=== "What people can do"

    1. **Request a catalog item**: pick a ready-made item; most fields fill in.
    2. **Request something custom**: describe an item that isn't in the catalog.
    3. **Attach a vendor quote**: upload it; the amount is read from it.
