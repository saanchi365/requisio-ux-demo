# Use cases

*Made-up content for the Requisio demo.*

## Raising requests
1. **Request a catalog item**: the requester picks a ready-made item (e.g. "Standard laptop"), and most fields fill in.
2. **Request something custom**: the requester describes an item that isn't in the catalog.
3. **Attach a vendor quote**: the requester uploads a quote; the amount is read from it.

## Approving
4. **Approve or reject**: an approver decides, giving a reason when rejecting.
5. **Ask for changes**: an approver sends the request back; the requester edits and resubmits.
6. **Delegate**: an approver hands the decision to someone else while away.

## Tracking
7. **Find a request**: search and filter the list by status, category or date.
8. **See request details**: status, approval route, history and comments.

## Setting up (admin)
9. **Set up departments and approvers.**
10. **Set up categories.**
11. **Set up approval rules** by amount and category.
